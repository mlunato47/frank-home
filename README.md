# Frank

  Frank is a private, self-hosted home assistant used only by one household.

  ## Privacy policy

  Frank uses Google's Smart Device Management API to read and adjust the
  household's own Nest thermostats when a household member asks. Thermostat
  data is used only to answer those requests. It is stored only on the
  household's own computer, is never sold or shared with anyone, and is not
  used for advertising. Access can be revoked at any time at
  https://myaccount.google.com/connections.
